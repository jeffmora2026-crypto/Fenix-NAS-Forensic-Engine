# Fenix Security Skill

## Overview
High-efficiency, lightweight security skill designed for real-time log inspection, file integrity verification, and storage anomaly detection in Network Attached Storage (NAS) environments. Operates completely offline with minimal resource overhead.

## Core Capabilities
- **Forensic Data Audit:** Automated scan of storage access logs and metadata trace vectors.
- **Directory Anomaly Cross-Referencing:** Multi-volume quota discrepancy analysis and unauthorized overflow reporting.
- **Integrity & Security Validation:** Detection of checksum mismatches, permission escalation, and anomalous bulk modifications.
